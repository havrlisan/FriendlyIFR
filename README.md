# FriendlyIFR

Browser-based IFR radio-navigation trainer for the Aeronautics department at the Faculty of Transport and Traffic Sciences, University of Zagreb.

- **App:** https://havrlisan.github.io/FriendlyIFR/
- **Documentation:** https://havrlisan.github.io/FriendlyIFR/docs/

Run locally: `python -m http.server 8000` from the repo root and open http://localhost:8000/.
